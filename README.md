# Wadhu

**Wadhu, by Gotigin: Tools · Apps · More.** Gotigin's home for reusable
code: the libraries, tools and apps that other Gotigin brands' apps need
(Kumkaj and future brands), written so that anyone else can use them too.

**Every part stands alone.** An app never depends on a sibling app, a
crate never depends on a sibling crate, and apps take crates like any
third-party dependency. One part changing never forces a sibling to
change. Doctrine:
[`docs/WADHU_VISION_AND_PRINCIPLES.md`](docs/WADHU_VISION_AND_PRINCIPLES.md);
enforced by `scripts/check-independence.sh`.

Rust (edition 2024) on **Makepad 2**, vendored at `vendor/makepad` from
the same pinned upstream commit and patch set as the other Gotigin
workspaces.

## Layout

| Path | What |
|---|---|
| [`apps/`](apps/README.md) | Independent apps and tools (package `wadhu-<app>`) — first: [`sms-gateway`](apps/sms-gateway/README.md) |
| [`crates/`](crates/README.md) | Reusable, self-contained libraries (package `wadhu-<crate>`) |
| [`sites/`](sites/README.md) | Makepad 2 fullpage sites |
| [`tools/`](tools/README.md) | One `cargo <app>-dev` shim per app |
| [`templates/`](templates/README.md) | Starters for new apps and crates (kept compiling) |
| `scripts/` | Tooling that names no app: Makepad setup, env, icons, scaffolding, checks |
| `patches/makepad/` | Patches applied on upstream Makepad 2 |
| `vendor/` | Generated by `scripts/setup-makepad.sh` (gitignored) |
| `assets/` | Brand master (`images/`) and default window icons (`icons/`) |
| [`docs/`](docs/README.md) | Wadhu-wide docs |

## Quick start

```bash
./scripts/setup-makepad.sh             # once, and after changing patches
cargo build --workspace --all-targets
cargo test --workspace
./scripts/check-independence.sh

cargo template-app-dev                              # run the template app (--hot --remote)
cargo run -p wadhu-template-widgets --example demo  # run the widget-crate demo

./scripts/new-app.sh <name> [--id com.example.app] [--label "Name"]
./scripts/new-crate.sh <name> [--widgets]
```
