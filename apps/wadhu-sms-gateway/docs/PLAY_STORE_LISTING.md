## Full description (≤4000 characters)

```
SMS Gateway is a product under Wadhu (Memon for more — Tools · Apps · More), a brand of Gotigin. It turns an Android phone or tablet with a SIM into an SMS radio for your own apps and shop systems.

Install on a device you control. Client apps send SMS over your LAN or Bluetooth — no cloud account required for local use. An optional SMS Relay can reach internet clients when you choose to enable it.

WHO IT IS FOR
Developers and businesses that need programmatic SMS from a real SIM: local shop tools, brand apps, automation on your network. Not a consumer chat client and not a bulk spam blaster.

LOCAL-FIRST
• LAN HTTP API with an API token you create on the device
• Bluetooth pairing for nearby clients
• Message queue and status on the gateway device
• Optional relay for remote clients — never required for LAN/Bluetooth

HOW TO START
1. Install SMS Gateway on an Android device with a SIM
2. Grant SMS / related permissions the app requests
3. Note the API token and device address from the gateway screen
4. Point your client (or curl) at the device and send a test message

PRIVACY & POLICY
Local LAN/Bluetooth traffic stays on networks you control. See the Privacy policy URL on this listing (same document as wadhu.com/privacy). Data deletion instructions: wadhu.com/data-deletion.

Website: https://wadhu.com
Support: support@gotigin.com

SMS Gateway is part of Wadhu — Tools · Apps · More — by GOTIGIN SOFTWARE & HARDWARE PRIVATE LIMITED.
```
