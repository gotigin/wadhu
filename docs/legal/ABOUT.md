## What Wadhu is

Wadhu is Gotigin’s brand for reusable tools — crates, apps, and services that
other Gotigin brands (and anyone else) can use. It is not the company name and
not a substitute for the Gotigin trademark.

## Products

- **SMS Gateway** — Android-first SIM messaging; LAN / Bluetooth free forever
  (`com.wadhu.smsgateway`)
- **SMS Relay** — optional internet plane to paired gateways
- **Wadhu Connect** — WhatsApp Cloud API Tech Provider bridge at
  [connect.wadhu.com](https://connect.wadhu.com)
