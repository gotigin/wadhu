# Names — do not mix these

| Word | What it is | Not |
| --- | --- | --- |
| **Wadhu** | Product **brand** (*Tools · Apps · More*) | Not the company; not a Meta app synonym for Gotigin |
| **Gotigin** | **Trademark** / house mark (Memon *find it*, *go-tee-geen*; slogan *Where Technology Meets Discovery*) | Not a Wadhu product name; not “Gotigin Connect” |
| **GOTIGIN SOFTWARE & HARDWARE PRIVATE LIMITED** | Legal **company** (CIN, GSTIN, contracts, Meta Business) | Not interchangeable with the Wadhu brand name in product UI |
| **SMS Gateway** | Wadhu **product** (`com.wadhu.smsgateway`) | Not “Gotigin SMS” |
| **Wadhu Connect** | Wadhu **product** (WhatsApp Cloud API Tech Provider bridge; host connect.wadhu.com; folder `apps/wadhu-connect`) | Not “Gotigin Connect”; there is no `apps/gotigin-connect` |

Other Gotigin brands (Kumkaj → Khaynjo, …) keep their own product names and
privacy URLs. Wadhu crates stay brand-neutral for those apps to consume.

Site / store / Meta paste must follow this table. Canonical privacy for Wadhu
products: [`legal/PRIVACY.md`](legal/README.md) → https://wadhu.com/privacy.
