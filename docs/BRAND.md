# Names — do not mix these

**Order is always Trademark → Company → Brand → Product.**

| Word | What it is | Not |
| --- | --- | --- |
| **Gotigin** | **Trademark** / house mark meaning *find it* in Memon, pronounced *go-tee-geen*; slogan *Where Technology Meets Discovery* | Not a Wadhu product name; not “Gotigin Connect” |
| **GOTIGIN SOFTWARE & HARDWARE PRIVATE LIMITED** | Legal **company** (CIN, GSTIN, contracts, Meta Business) · mearaj@gotigin.com | Not interchangeable with the Wadhu brand name in product UI |
| **Wadhu** | Product **brand** — Memon *more*; *Tools · Apps · More*. Reusable tools, utils, and apps | Not the company; not a messaging brand; not a Meta app synonym for Gotigin |
| **SMS Gateway** | Wadhu **product** (`com.wadhu.smsgateway`) | Not “Gotigin SMS”; not the Wadhu brand itself |
| **SMS Relay** | Wadhu **product** (optional internet path to a paired gateway) | Not required for local SMS |
| **Wadhu Connect** | Wadhu **product** (WhatsApp Cloud API Tech Provider bridge; host connect.wadhu.com; folder `apps/wadhu-connect`) | Not “Gotigin Connect”; there is no `apps/gotigin-connect`; not the Wadhu brand itself |

Other Gotigin brands (Kumkaj → Khaynjo, …) keep their own product names and
privacy URLs. Wadhu crates stay brand-neutral for those apps to consume.

Site / store / Meta paste must follow this table. Canonical privacy for Wadhu
products: [`legal/PRIVACY.md`](legal/README.md) → https://wadhu.com/privacy.
